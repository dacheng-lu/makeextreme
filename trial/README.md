# trial/

Step-0 probes of three existing tools (see `../docs/STEP0_同类试跑.md`). They ran once on the author's machine and
the scripts still carry that machine's paths (`~/study/...`, `~/.hermes/...`), so they are kept as evidence of what
was measured, not as something to run elsewhere. In `result_dvc.json` the absolute home directory of the run was
replaced by `$HOME`; nothing else was changed.
